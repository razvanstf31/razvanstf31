# Setup

1. Create a **public** GitHub repository named exactly `razvanstf31`.
2. Upload the contents of this folder to the repository root, including `.github`.
3. Keep `README.md` at the root. GitHub renders it on your profile.
4. Open **Actions** → **Generate contribution snake** → **Run workflow** once.
5. If publishing fails, check Settings → Actions → General → Workflow permissions and allow read/write access.

The design uses a dark sci-fi interface with cyan/violet neon accents and custom SVG assets.
